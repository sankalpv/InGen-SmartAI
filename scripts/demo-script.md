## 📋 Pre-Recording Checklist

Before hitting record, make sure:

- [ ] **Outlook is open** with a healthy inbox (50+ emails visible for the hook shot)
- [ ] **InGen is running** at `localhost:3000` with fresh data
- [ ] **AI Briefing is cached** — load the dashboard once before recording so the briefing appears instantly
- [ ] **At least one urgent email** exists in the 🔴 Respond Now lane
- [ ] **Week Ahead has data** — verify 7-day calendar has meetings populated
- [ ] **Leadership page has data** — check relationship health cards show names
- [ ] **Team Health has goals** — WBR board should have colored status cards
- [ ] **Code Metrics has data** — engineer table should have sparklines populated
- [ ] **Ticket Health has data** — resolver groups should show open ticket counts
- [ ] **Dark mode is active** (more cinematic for recording)
- [ ] **Sidebar is expanded** at the start
- [ ] **Browser is full-screen** or maximized, no bookmarks bar, clean chrome
- [ ] **Font size is readable** at recording resolution (consider 110% zoom)
