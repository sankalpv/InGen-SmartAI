Integrations & Architecture

Privacy-First Architecture

All AI processing runs locally. No data leaves your machine. Integrates with Outlook, Quip, and Phonetool.

📬
Microsoft Outlook
Direct local integration via AppleScript. Emails, calendar events, and attendee information. Background sync every 15 minutes.
📄
Amazon Quip
Auto-detects Quip URLs in emails. Fetches document content via MCP protocol for rich AI context.
👥
Amazon Phonetool
Fetches direct reports by alias. Full names resolved. 24-hour cache with file persistence.
🧠
Local AI Engine
Ollama with qwen3/llama3. 4096-dimension embeddings. hnswlib vector store. SQLite persistence. Zero cloud dependency.
🏗️
Technology Stack
Modern, production-grade architecture designed for speed and privacy.
